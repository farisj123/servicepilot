
# ServicePilot

**Cross-platform IT Service Management and AI-assisted support.**

ServicePilot is an open-source portfolio project exploring how small teams can manage support incidents, organise troubleshooting knowledge and understand service performance through analytics.

## Goals

- Manage and track IT support tickets.
- Record incident priorities, status changes and resolutions.
- Maintain a searchable troubleshooting knowledge base.
- Visualise service desk metrics and recurring issues.
- Explore responsible AI-assisted troubleshooting.
- Support web, Android and iOS through a shared application codebase.

## Technology

- Frontend: Expo, React Native and TypeScript
- Backend: Python and FastAPI
- Database: PostgreSQL
- Testing: Pytest and frontend automated tests
- Development: Docker and GitHub Actions

## Project status

Early development. Features will be documented as they are implemented and tested.

## Learning objectives

This project demonstrates practical learning in IT support, IT Service Management, API development, database design, testing, security and cross-platform application development.
